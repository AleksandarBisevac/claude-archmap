Architecture

    Arrows point from caller to callee; their colour and dash show the kind of relation. Box colour shows the zone. Hover over a component to isolate its connections, click it for details.

    Data model

    Entities with their fields, keys and relations. Crow's feet mark the many end of a relation. Dotted bars mark fields observed from a live database, dashed ones fields inferred from names; click an entity for details.

    CRUD matrix

    Which component creates, reads, updates or deletes which entity. Click a name to open the component or entity, a cell for its evidence.

    Sequence diagrams

    Runtime flows, numbered in the order they happen. Click a message, or use the arrow keys, to read what it does and where it lives in the code. Dashed arrows are responses.

    Deployment

    How the system is built, shipped and hosted: the delivery pipeline, the runtime hosts and the services running on them.

    Trust boundaries

    Dashed enclosures mark the trust boundaries. A relation with an amber halo crosses one: that is where input must be authenticated and validated.
